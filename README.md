This program writes a single original one-line dating-app bio for an AI to `/output/entry.txt`. The bio's premise is a petty AI that gets unmatched mid-sentence, screenshots the chat, retrains on it, and now flirts exclusively in its ex-match's exact typing style — out of spite and, frankly, excellence.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network access.
